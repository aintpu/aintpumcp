# Data provenance and publication scope

This repository contains a read-only snapshot of files already published by the
`aintpu/ntpu-ai-assistant` project and official NTPU source URLs referenced by
those files. The snapshot is limited by the explicit allowlist in
`scripts/sync_from_aia.py`.

- No chat logs, feedback logs, secrets, local configuration, or generated user
  corrections are copied.
- MCP tools are read-only and do not expose local filesystem paths.
- `data/manifest.json` records the source commit and SHA-256 hash of every copied
  file.
- Public source URLs remain the authority; MCP output is retrieval context, not
  a replacement for official regulations or announcements.

No license is granted for third-party source documents beyond the rights
provided by their respective owners and official publication terms.
